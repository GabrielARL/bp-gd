# Repository instructions

This repository contains the compact BP–GD research record and the one
performance-verified gradient decoder selected for continued work.

Before changing an experiment, result claim, explainer, slide, or caption,
read and follow:

1. `.agents/skills/bp-gd-mechanism-study/SKILL.md`
2. `.agents/skills/bp-gd-terminology/SKILL.md` for reader-visible technical wording
3. `.agents/skills/bp-gd-writing/SKILL.md` for reader-visible explanations

Do not copy another historical implementation into this repository merely to
compare it. Record closed-branch provenance in the research tree and reopen a
branch only when a prospective card identifies a genuinely new operation or
coordinate system.

Do not call the state-dependent two-hop positive-matrix fit a decoder or a
performance result until it passes an independent direction screen and a
decoder evaluation on preregistered cases.

Do not broaden the current question to ADMM unless the user explicitly opens a
separate research question.
